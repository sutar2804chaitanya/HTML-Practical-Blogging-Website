# HTML Practical Blogging Website

A multi-page Blogging Website developed using HTML, CSS, and JavaScript to demonstrate fundamental web development concepts, semantic HTML structure, multimedia integration, and user interaction features.

## Project Overview

This project was created as an academic web development assignment to showcase the practical implementation of HTML elements through a real-world blogging website. The website follows a gaming-themed design and includes multiple interconnected pages with navigation, forms, multimedia content, and support sections.

## Features

### Home Page

* Project introduction and overview
* Navigation menu for easy access
* Responsive and clean layout

### Blog Content Page

* Blog article presentation
* Lists, tables, and formatted content
* Gaming-themed content structure

### User Registration Form

* Multiple HTML input types
* File upload support
* Textarea and fieldset implementation
* Interactive dialog box using JavaScript

### Media Gallery

* Image display with captions
* Audio and video integration
* Embedded content using Embed and Iframe tags

### Help & Support Page

* User guidance section
* Support availability information
* Contact and assistance details

## Technologies Used

* HTML5
* CSS3
* JavaScript
